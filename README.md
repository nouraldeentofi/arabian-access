# موقع أريبيان أكسس (Arabian Access) — نموذج أولي

موقع شركة استشارات تأسيس أعمال في الرياض. صفحة واحدة بالعربي (افتراضي) ونسخة إنجليزية كاملة، نهاري افتراضيًا وفيه زر قمر للوضع الليلي، ومبني على الجوال كأنه تطبيق.

**الفكرة:** الموجتان في شعارهم (حسب وصفهم على لينكدإن: لونان = شراكة الشركة مع العميل) تمشيان سوا في خلفية الهيرو وفي قسم «كيف نعمل»، فوق نقشة النجوم المحفورة على زجاج استقبال مكتبهم بالملز، وفيها نقاط ضوء تتحرك على خطوطها.

## وين تعدّل

- **كل النصوص (عربي + إنجليزي):** `src/content.py` (القاموس `T["ar"]` و `T["en"]`).
- **الإعدادات:** `CONFIG` أول `src/content.py`:
  - `BASE_URL` الدومين النهائي (حاليًا `https://arabianaccess.com`)، منه بيطلع canonical و sitemap و llms.txt.
  - `PROTOTYPE: True` يعني الصفحات `noindex`. بعد موافقة صاحب الشركة خليها `False` وابنِ من جديد.
  - `PHONE`، `WHATSAPP`، `EMAIL`، روابط السوشال، `MAPS_URL`، `HOURS` (أيام وساعات الدوام، للشارة الحية والتقويم)، و `MAKER` (رابط موقعك).
- **الألوان والخطوط والحركة:** `src/assets/style.css` (المتغيرات بأول الملف تحت `:root`، والليلي تحت `[data-theme="dark"]`).
- **السلوك (الفورم، التقويم، السحب، الشارة الحية…):** `src/assets/site.js`.
- **الصور:** `src/raw/` (reception / building / sign). بدّل الملف بنفس الاسم وابنِ.

## البناء

```bash
cd src
python3 make_media.py     # مرة وحدة: صور المشاركة og + أيقونات (يحتاج Playwright)
python3 build.py          # يطلع الموقع بـ dist/
python3 make_preview.py   # نسخ ملف واحد للمعاينة بـ preview/
```

الناتج بـ `dist/`: `index.html` (عربي)، `en/index.html`، `assets/`، `robots.txt`، `sitemap.xml`، `llms.txt`، `llms-full.txt`.

الاختبارات: `cd dist && python3 -m http.server 8765` وبعدين `python3 tests/test_site.py`.

## دومين خاص

1. ارفع محتوى `dist/` على GitHub Pages أو Cloudflare Pages.
2. خلي `BASE_URL` = الدومين، و `PROTOTYPE` = `False`، وابنِ من جديد وارفع.
3. انتبه: `arabianaccess.com` شغّال حاليًا بموقعهم القديم (WordPress إنجليزي). التحويل يصير من إعدادات DNS عندهم (CNAME على Pages) بعد موافقتهم.

## الذكاء الاصطناعي والبحث

- كل المحتوى مكتوب جاهز بالـ HTML (ما بيحتاج JavaScript ليظهر).
- JSON-LD: `ProfessionalService` (أسماء بديلة وأخطاء إملائية شائعة، العنوان، الإحداثيات، الدوام، الخدمات التسع كـ `Service`، `FAQPage`) بدون تقييمات مكتوبة بإيدنا.
- `robots.txt` يرحّب بـ GPTBot و ClaudeBot و PerplexityBot و Google-Extended وغيرهم، و hreflang عربي/إنجليزي، و Open Graph بصورة لكل لغة.
